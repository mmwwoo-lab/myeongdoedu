# 품질 검증 보고서

작성일: 2026-11-25 (Asia/Seoul)
담당: 품질검증 담당자

## 업무 지시서

비서실장 지시에 따라 얼굴 문화 체험 앱의 요구사항 충족, 실패 경로, 개인정보 처리, 접근성을 검토한다. 메인 소스 수정 권한 없이 발견 사항을 개발 담당자에게 전달한다. 실제 브라우저 조작은 메인 개발 담당자가 수행한다.

## 검증 기준

- 사진 업로드: 이미지 종류·용량 검증, 손상 파일 오류, 새 사진 교체와 이전 자원 해제.
- 카메라: 사용자 동작 후 권한 요청, 거절·미지원 안내, 촬영·취소·탭 이탈 시 스트림 종료.
- 입력: 실명 대신 별명, 나이·성별 입력창, 선택 여부 명시, 입력값 안전 출력.
- 형태 관찰: 얼굴 검출 불가·다중 얼굴·모델 실패 처리, 자동값 수정 가능, 실제 성격·운명 추론 금지.
- 결과: 결과 그림에 관찰 특징 반영, 관상 문화 설명의 비과학적 성격 표시, 재입력 시 결과 갱신.
- 자료: 유형별 시각 설명과 근거 출처, 차별적·단정적 문구 배제.
- 보고서: 결과 다운로드 실행, 개인 사진 포함 여부 명시, 출력 파일 문법 확인.
- 삭제: 사진·입력·측정·결과 메모리와 캔버스 초기화, 카메라 종료.
- 반응형·접근성: 폼 라벨, 키보드 접근, 포커스, 상태 알림, 모바일 폭, 대비, reduced-motion 대응.
- 개인정보: 사진 외부 전송·영구 저장 없음, 제3자 리소스 의존 공개.

## 현재 상태

순수 함수 자동 테스트 8개, 비동기 흐름 통합 시뮬레이션 6개, JavaScript 문법 검사를 통과했다. 소스 리뷰에서 발견한 4개 보완 사항은 수정된 소스에서 재확인했다. 실제 범위와 한계를 아래에 기록한다.

## 소스 검토

확인한 사항: 한국어 문서 언어, 폼 라벨, 본문 바로가기, 상태 알림, 결과 포커스 지점, 개인정보 대화상자, 사진 동의, 파일 형식·용량 검사, 이미지 재인코딩, 다중 얼굴 거절, 검출 실패 시 직접 선택, 카메라 화면 숨김 처리, 원본 사진을 제외한 결과 다운로드.

앱 자체 코드에서 사진 업로드 요청이나 `localStorage`, `sessionStorage`, `indexedDB`, `sendBeacon`, WebSocket 사용을 발견하지 않았다. 모델·WASM은 같은 사이트 경로를 사용한다. 이는 소스 검토 결과이며 실행 중 네트워크 트래픽 캡처를 대체하지 않는다.

개발 담당자에게 전달하고 수정 소스에서 재확인한 보완 사항 (4개 모두 해결):

1. TXT 다운로드 앞의 BOM이 문자 그대로의 `\\uFEFF`로 추가되는지 확인하고 실제 BOM으로 수정.
2. 취소한 분석 요청과 새 분석 요청이 동일한 모델 생성 Promise를 기다릴 때, 취소 요청이 공유 모델을 닫아 새 요청이 실패할 수 있는 경합 보완.
3. 촬영의 비동기 이미지 생성이 끝난 뒤 요청 유효성을 확인하기 전에 카메라를 중지하는 순서 보완. 오래된 촬영이 새 카메라를 종료하지 않도록 요청 번호와 카메라 번호 함께 확인.
4. 모두 삭제 시 숨겨진 결과 DOM에 남은 별명과 결과 설명도 비우도록 보완.

## 검증 한계

이 담당자는 실제 브라우저를 조작하지 않았다. 메인 개발 담당자의 브라우저 검증 기록이 별도로 제공되어야 한다. 실제 카메라 장치·권한 거절 UI·손상 이미지·실제 인물 사진의 모델 검출·서로 다른 피부색과 연령·모바일 실기기·스크린리더 사용성·호스팅 접속 로그 정책은 본 자동 테스트로 검증하지 않았다.

합성 특징점 테스트는 코드 동작을 확인한다. 얼굴형 기준의 객관적 정확성이나 관상의 과학적 타당성을 입증하지 않는다. 이 앱의 분류는 실험적 형태 구분이며 개인의 성격·건강·능력·운명 판정에 사용해서는 안 된다.



## 최종 수정 재검증

- 모델 생성 수명을 요청 취소 번호와 분리한 `modelGeneration`으로 관리함을 확인했다. 오래된 분석 요청이 다른 요청과 공유 중인 모델을 닫지 않는다.
- 촬영의 `toBlob` 완료 후 분석 번호와 카메라 번호를 먼저 비교하고, 유효한 요청일 때만 현재 카메라를 중지한다.
- 결과 초기화 시 별명·설명·SVG·태그 DOM을 비운다.
- TXT 다운로드의 BOM은 `String.fromCharCode(0xfeff)`를 사용한다.
- CSS 본문·입력·보조글자 크기 보완을 개발 담당자가 반영했다. 실제 가독성은 브라우저 검증 기록을 따른다.

### 비동기 흐름 통합 시뮬레이션

실행: `node --experimental-vm-modules tests/face-story/integration.mjs` — 6개 통과.

실제 `app.mjs`를 Node VM에서 실행하고 DOM·카메라·이미지·모델 API를 테스트 대역으로 제공했다. 앱 로직의 경합을 재현하는 검사이며 실제 브라우저 API의 동작 검사가 아니다.

| 흐름 | 결과 |
| --- | --- |
| 모델 로딩 중 요청 취소 후 새 분석이 같은 모델을 공유 | 통과: 취소 요청이 공유 모델을 닫지 않음 |
| 전체 삭제 | 통과: 별명·결과 DOM·사진 URL 제거, 모델 종료 |
| 오래된 촬영 완료 후 새 카메라 유지 | 통과: 이전 촬영이 새 스트림을 끄지 않음 |
| 카메라 취소 | 통과: 현재 트랙 종료 |
| 모델 로딩 중 모두 삭제 | 통과: 늦게 생성된 모델 종료, 결과 다시 표시되지 않음 |
| 카메라 권한 대기 중 모두 삭제 | 통과: 늦게 획득한 카메라 트랙 종료 |

최종 수정 후 순수 함수 8개와 앱 문법 검사도 다시 통과했다. 메인 개발 담당자는 브라우저에서 예시 하트형 결과의 별명 표시와 전체 삭제 후 결과 DOM이 비는 동작을 확인했다고 보고했다. 실제 사진 자동측정·모바일·카메라 실기기 결과는 메인 개발 보고서를 참조한다.
