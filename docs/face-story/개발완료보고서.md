# 명도재 이명우의 관상앱 — 개발 완료 보고서

작성일: 2026년 11월 25일 · 총괄: 비서실장 역할의 개발 조정 담당

## 개발 결과

사진 선택 또는 카메라 촬영으로 얼굴의 시각적 형태를 살펴보고, 단순한 얼굴 그림과 설명을 만드는 한국어 반응형 웹앱을 구현했다. 개인의 성격·능력·건강·재물·운명을 얼굴에서 판단하는 기능은 제공하지 않는다. 전통 관상은 문화 배경으로 소개하고, 유형별 상징 감상은 앱이 창작한 문구로 구분했다.

## 요구사항 이행

| 요구사항 | 구현 |
| --- | --- |
| 사진·카메라 얼굴 입력 | JPG/PNG/WebP, 15MB 제한, 정면 단독 사진 안내, 촬영·취소 |
| 실명 대신 별명 | 별명 20자, 나이 1~120세, 성별·응답 안 함. 모두 선택 입력 |
| 얼굴 형태 확인 | 브라우저에서 MediaPipe 특징점을 검출, 실험적 비율 기준으로 분류 |
| 오류 복구 | 검출 실패·환경 미지원은 직접 선택임을 표시, 두 얼굴 검출은 재입력 안내 |
| 유형별 자료 | 얼굴형 5종, 눈썹·눈·입술 각 2종, 배경 출처와 창작 도상 설명 |
| 간단한 그림 | 40가지 조합의 SVG 얼굴 도식, 부위별 관찰 태그 |
| 설명과 저장 | 결과 설명, SVG 그림·TXT 설명 다운로드, 사진 없는 예시 |
| 개인정보 | 사진·폼 값 서버 전송 없음, 영구 저장 API 없음, 삭제·카메라 종료 |
| 보고서 | 앱 안의 개발 보고서 화면, 본 보고서, 유형·개인정보·품질 부록 |

## 개인정보 처리 흐름

사진 선택 → 메모리에서 축소·재인코딩 → 임시 Blob URL 미리보기 → 동일 사이트의 모델을 내려받아 기기 안에서 검출 → 형태 확인 → 결과 표시 → 사용자가 원하는 결과만 파일 저장.

원본 사진이나 얼굴 특징점을 저장·업로드하는 API는 없다. 별명·나이·성별은 페이지 메모리에만 있으며, 나이와 성별은 형태 분류나 설명 생성에 쓰지 않는다. JPG 재인코딩으로 미리보기에는 원본 EXIF를 복사하지 않는다. 다운로드 그림에는 사진과 프로필이 없고, TXT에는 별명만 포함한다.

카메라는 촬영·취소·화면 숨김·다른 메뉴 이동·종료 때 트랙을 중지한다. 전체 삭제는 입력과 사진 URL, 결과 DOM, 모델을 해제하고, 늦게 끝난 분석이나 권한 요청이 결과를 복원하지 않도록 처리한다. 직접 저장한 파일은 사용자가 기기에서 지워야 한다. 호스팅 제공자의 IP·일반 접속 로그는 별도이며 법률 준수를 보증하는 문서는 아니다.

## 검증 결과

- JavaScript 문법 검사 통과.
- 순수 함수 테스트 8개: 5종 분류·경계값·비정상값·합성 특징점·해상도 비율·40가지 SVG·문자열 이스케이프·설명 파일 출력.
- 앱 통합 시뮬레이션 6개: 공유 모델의 취소 경합, 전체 삭제, 늦은 촬영, 카메라 취소, 모델 생성 중 삭제, 권한 대기 중 삭제.
- 실제 브라우저: 첫 화면 표시, 사진 없는 예시, 하트형 선택, 별명 표시, 그림·설명 결과, 전체 삭제 후 입력·결과 DOM 빈값 확인.
- 공개 Google MediaPipe 예제 사진을 파일 선택으로 입력하고, 기기 내 자동 측정·특징 확인·타원형 결과 생성·삭제를 실제 브라우저에서 확인. 사용자 사진은 테스트에 사용하지 않았다.
- 코드 검토에서 폼 값의 URL 노출 가능성, 숨겨진 결과 DOM 잔존, 모델·촬영 경합, TXT BOM 문제를 발견하고 수정·재검증했다.

실제 카메라 장치와 운영체제 권한 UI, 다양한 연령·피부색·조명에 대한 측정 정확도, 모든 모바일 실기기와 스크린리더는 검증하지 않았다. 합성 테스트와 예제 1장 통과는 분류 정확도나 관상의 과학적 타당성을 입증하지 않는다. 자동 결과는 반드시 사용자가 확인할 수 있도록 만들었다.

## 실행과 유지보수

앱은 설치나 API 키가 필요 없는 정적 HTML/CSS/ES module이다. 동일 폴더의 MediaPipe JS·WASM·모델을 사용하므로 분석 중 제3자 CDN에 사진을 보내지 않는다. 최초 모델 로딩에는 약 14MB 안팎의 자산 전송과 기기 연산이 필요하다. 전체 배포 자산에는 SIMD 미지원용 대체 WASM도 포함한다.

로컬 소스 폴더에서 `node server.mjs`를 실행한 뒤 `http://127.0.0.1:4173`을 연다. 카메라는 HTTPS 또는 localhost와 사용자 권한이 필요하다. HTML 파일을 직접 더블클릭하는 `file://` 실행은 모듈·모델 로딩을 보장하지 않는다.

지정 저장소 `mmwwoo-lab/myeongdoedu`의 배포 디렉터리 설정을 확인하여 `public/face-story/`에 통합한다. 기존 학습앱 목록에 새 앱 링크를 추가하며, 상세 업무지시·검토·테스트는 `docs/face-story/`와 `tests/face-story/`에 제공한다. 원본·사용자 사진·테스트용 공개 인물 사진·비밀 키는 저장소와 배포물에 포함하지 않는다.
