# 명도재 이명우의 관상앱 — 최신 개발 완료 보고서

작성일: 2026년 11월 26일 (한국시간)

## 최신 결과

입력한 실제 사진에 얼굴 윤곽·눈썹·눈·입술의 위치를 붉은 선과 이름으로 표시하고, 같은 부위별 설명을 연결했다. 별도 얼굴 도식과 도상 감상문은 결과 및 유형 도감에서 제거했다. 관광지 사진 자판기 색상과 입체 버튼 디자인은 유지한다.

관찰 설명 뒤에는 전체 운세, 기회·관계·재물/소비·배움/생활의 분야별 이야기, 앞으로 12개월을 네 구간으로 나눈 상징 이야기, 토정비결풍 해설을 추가했다. 운세는 사용자가 선택한 관심 주제에 따른 창작이며 실제 얼굴에서 미래를 추론하지 않는다.

## 요청 이행과 업무 지시

| 담당·업무 | 최신 결과 |
| --- | --- |
| 비서실장·총괄 개발 | 사용자 추가 요청 통합, 실제 사진 표시·해설·운세·저장·삭제 구현 및 최종 검증 |
| 콘텐츠 조사 | 초기 콘텐츠 담당의 조사 자료를 참고하고, 총괄이 한국민족문화대백과 「토정비결」 추가 확인 |
| 개인정보 검토 | 초기 담당 검토 결과를 토대로 총괄이 사진 포함 다운로드와 연령별 제안의 처리 범위를 재검토 |
| 품질 검증 | 초기 담당의 테스트를 최신 구조에 맞춰 갱신하고, 총괄이 사진 표시·운세·실제 브라우저 흐름 추가 검증 |

초기 담당별 보고서는 이전 버전의 검토 기록이며, 최신 제품 동작은 이 보고서를 기준으로 한다.

## 화면과 결과

1. 닉네임(필수), 나이·성별(선택), 운세 이야기의 관심 주제를 입력한다.
2. 정면의 한 사람 사진을 고르거나 카메라로 촬영한다. 사진 사용 동의 후 기기 안에서 특징점을 검출한다.
3. 선택·측정한 형태를 확인한다. 자동 검출된 얼굴 윤곽·눈썹·눈·입술을 입력 사진 위에 붉게 표시한다.
4. 전체 관상 해설(500자 이내)과 사진 부분별 해설(각 200자 이내)을 단락으로 읽는다.
5. 창작 종합 운세·분야별 운세·12개월의 상징 이야기·토정비결풍 해설을 읽는다.
6. 사진 포함 감정서 PNG, 붉은 선 사진 PNG, 설명·운세 TXT를 선택 저장할 수 있다.

검출이 실패하면 선을 임의로 그리지 않는다. 사진은 그대로 표시하고 자동 표시가 없다는 설명을 보여 준다. 새로운 사진과 각도를 시도하거나 형태를 직접 확인할 수 있다.

## 토정비결 해설의 범위

문화 배경 자료는 한국민족문화대백과사전 「토정비결」(https://encykorea.aks.ac.kr/Article/E0059207)이다. 전통 방식은 나이 외에 생월·생일 등으로 괘를 구한다. 이 앱은 추가 생년월일을 수집하거나 정통 괘를 계산하지 않으며 ‘토정비결풍 창작’임을 표시한다.

나이는 화면의 생활단계 제안에만 활용하고, 성별은 프로필에만 표시한다. 성별에 따른 길흉 차등은 없다. 사진·얼굴·나이·성별로 실제 미래를 예측하거나 개인의 성격·건강·능력·재물을 판단하지 않는다. 운세 문장은 선택한 관심 주제별로 미리 작성한 문화·오락 콘텐츠다.

## 개인정보와 저장 범위

사진과 입력값은 브라우저 메모리에서만 처리한다. 외부 분석 API, 앱 서버 업로드, 영구 저장소, 추적 도구를 사용하지 않는다. 모델은 같은 사이트에서 내려받는다. 선택 사진은 축소·재인코딩하며 원본 EXIF를 복사하지 않는다.

사용자 최신 요청에 따라 감정서 PNG에는 처리한 입력 사진과 닉네임이 포함된다. 붉은 선 사진 PNG에는 처리한 사진이, TXT에는 닉네임과 설명·운세가 포함된다. 나이·성별·연령별 생활 제안은 저장 파일에서 제외한다. 파일 포함 내용을 버튼 근처에서 안내한다. 이미 저장한 사진 파일은 사용자가 기기에서 삭제해야 한다.

전체 삭제는 입력·사진 URL·표시 캔버스·설명·운세·모델을 해제한다. 카메라 촬영·취소·화면 숨김·종료 시 트랙을 중지한다. 늦은 분석·권한 요청·PNG 생성이 삭제한 결과를 복원하거나 저장하지 못하도록 요청 번호와 결과 스냅샷을 확인한다. 호스팅 사업자의 일반 접속 로그는 별개다.

## 검증

- JavaScript 문법 검사, 핵심 테스트 11개, 비동기 통합 시뮬레이션 6개 통과.
- 전체 40가지 형태 조합: 500/200자 제한·단락·TXT의 나이/성별 제외 검사 통과.
- 운세 4주제 × 11개 연령값(44조합): 성별 불변, 연령별 제안 분리, 정통 괘 미계산 표시, 분야·기간별 해설 확인.
- 사진 표시: 원본 비율 유지·최대1200px 축소·4개 관찰 부위의 붉은 선·검출 실패 무표시 검사 통과.
- 사진 포함 PNG: 입력 캔버스 사용, 텍스트 경계·나이/성별 제외·캔버스 해제 검사 통과.
- 실제 브라우저: 공개 MediaPipe 예제 사진으로 자동 검출·붉은 선 위치·겹치지 않는 라벨·관상 해설·운세·토정비결풍 해설·PNG 생성 후 저장 요청 완료 확인.
- 390px 모바일에서 가로 넘침 없음. 결과에 별도 얼굴 SVG가 없음을 확인.
- 전체 삭제 후 표시 캔버스 폭0, 운세 문구·닉네임 빈값, 결과 숨김 확인.

테스트 사진은 사용자 개인 사진이 아닌 Google MediaPipe의 공개 예제 사진이다. 실제 카메라 장치·권한 UI, 다양한 집단의 측정 정확도, 다운로드한 PNG의 디스크 화상 검증은 별도 항목이다. 형태 분류는 실험적 비율 기준이며 과학적 관상 판정이 아니다.

## 실행

독립 소스 묶음에서 `node server.mjs` 실행 후 `http://127.0.0.1:4173`에 접속한다. 카메라는 HTTPS 또는 localhost와 사용자 권한이 필요하다. 모듈·모델을 불러오므로 file:// 직접 실행 대신 HTTP 서버를 사용한다.
