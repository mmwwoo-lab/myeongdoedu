# 금연 테트리스게임

명도재 바이브코딩연구소에서 바이브코딩으로 개발한 금연 응원 게임입니다.

## 실행

- 공개 게임: https://breathe-blocks-mmw-20261121.korea8014lee.chatgpt.site
- 이 저장소의 배포 파일: `public/quit-tetris/index.html` (외부 파일 없이 실행되는 단일 HTML)
- 웹 설명서: `public/quit-tetris/manual.html`
- 개발 소스: 이 폴더의 `dist/`

개발 미리보기는 이 폴더에서 `node serve.cjs`를 실행하고 `http://127.0.0.1:4173`을 엽니다.

## 규칙과 소리

10줄마다 승급하며 10단계에서 10줄을 지우면 최종 클리어입니다. 시작 등급을 선택할 수 있습니다.
소리 ON에서 반복 리듬과 자동 낙하 박자음이 나옵니다. 배경 리듬은 1단계 84 BPM부터 등급마다 10 BPM씩 증가해 10단계 174 BPM이 됩니다.
일시 정지, 호흡, 등급 선택, 게임 종료에서는 음악이 멈춥니다. OFF는 음악과 효과음을 모두 끕니다.

## 조작

방향키 이동, 위 방향키 또는 X 회전, Z 반대 회전, SPACE 바로 놓기, C 보관, P 일시 정지, B 숨 고르기. 화면 버튼도 지원합니다.

## 검사

```sh
node verify.cjs
node verify-audio.cjs
```

게임 규칙 검사 20개와 오디오 검사 18개를 포함합니다. 배포 파일은 소스를 수정한 뒤 CSS와 JavaScript를 인라인으로 합쳐 다시 생성해야 합니다.
