처음 오셨나요? 스킬 사용 설명서

스킬은 AI에게 역할, 제작 방법, 결과물 기준을 알려주는 작업 지침입니다. 코딩 경험이 없어도 아래 순서대로 사용할 수 있습니다.

01. 분야 선택검색창이나 색상별 분야 버튼으로 원하는 스킬을 찾습니다.
02. 수준 선택요약은 빠른 시작, 상세는 단계별 실행, 전문가는 전체 규격과 원문 부록 확인에 사용합니다.
03. 복사 또는 저장현재 선택한 스킬을 복사하거나 MD 파일로 저장합니다.
04. AI에 입력ChatGPT 또는 사용 중인 코딩 도구에 붙여넣고 주제·자료·조건을 추가합니다.
05. 제작 및 검수결과를 확인하고 수정합니다. 외부 도구, API 및 배포 권한은 별도로 필요합니다.

‘서정시 창작 잼’의 요약 스킬을 복사하여 AI 대화창에 붙여넣고, 마지막에 “늦가을 신천의 은행잎을 소재로 시를 창작해 주세요.”라고 추가해 보세요. 결과가 마음에 들지 않으면 상세 스킬로 바꾸거나 수정 조건을 알려 주세요.

MD 저장은 작업 지침을 파일로 보관하는 기능입니다. 파일을 저장했다고 AI 도구에 자동 설치되지는 않습니다.
