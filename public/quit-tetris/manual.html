제작 6단계 리듬 배경음과 효과음 만들기

블록이 내려가는 동안 리듬이 이어지고, 높은 등급일수록 음악이 빨라지게 합니다.

음원 파일 없이 브라우저 오디오로 반복 멜로디와 베이스와 박자음을 만듭니다. 1단계는 84 BPM이며 등급마다 10 BPM씩 올라 10단계는 174 BPM입니다. 자동 낙하에도 박자음을 넣습니다. 새로 열면 기본 ON이고 필요할 때 OFF로 끕니다. 실제 재생은 시작 버튼을 누른 뒤 진행합니다.

AI 요청 예시

소리 ON일 때 시작부터 종료까지 리듬 배경음이 계속 나오게 해줘. 블록이 내려갈 때도 박자음을 넣어줘. 1단계 84 BPM부터 등급마다 10 BPM씩 빠르게 해줘. OFF와 일시 정지와 호흡 화면과 게임 종료 때 음악을 멈추고, 다시 플레이하면 한 겹으로만 재생되게 해줘.

완료 확인

플레이 동안 음악이 반복됩니다. 10단계가 1단계보다 빠릅니다. OFF를 누르면 배경음과 효과음이 멈춥니다. 일시 정지와 호흡과 종료에서 음악이 멈추고 재개하면 다시 나옵니다. 빠르게 버튼을 눌러도 여러 배경음이 겹치지 않습니다.

제작 7단계 금속 케이스와 전자게임 색상 적용하기

기능을 유지하면서 금연 테트리스게임만의 화면 디자인을 완성합니다.

본체는 은회색 금속 케이스, 화면은 짙은 회색으로 만듭니다. 방향키는 게임판 바로 아래 중앙에 놓고 숨 고르기와 소리 버튼은 왼쪽에 놓습니다. 스코어는 형광 녹색, 블록 7종은 서로 다른 전자게임 색상이며 다음 블록과 보관 블록도 같은 색입니다.

제작 8단계 금연 표시와 숨 고르기 넣기

금연 응원 메시지와 잠깐 쉬는 기능을 게임에 연결합니다.

게임기 상단의 금연 아이콘과 금연 글자와 표시등을 빨간색으로 만듭니다. 집중등과 휴식등은 게임 상태를 보여줍니다. 숨 고르기를 누르면 게임을 멈추고 들이쉬기 4초와 내쉬기 6초를 3번 안내합니다. 이 표시는 실제 금연 여부를 측정하는 기능이 아닙니다.

제작 9단계 규칙과 화면을 나누어 테스트하기

코드 검사와 실제 플레이를 모두 수행해 배포 전 오류를 줄입니다.

게임 규칙은 자동 검사로 확인하고 화면과 입력은 브라우저로 확인합니다. 현재 프로젝트의 verify.cjs는 20개 게임 규칙 검사를, verify-audio.cjs는 18개 오디오 검사를 담고 있습니다. 오류는 발생 위치만 말하지 말고 시작 등급, 입력 순서, 기대 결과와 실제 결과를 함께 기록합니다.

AI 요청 예시

1줄부터 4줄 제거, 점수 계산, 보관 제한, 승급 경계, 10단계 승리와 재시작을 검사해줘. 1단계와 10단계 시작, 등급 변경 취소, 키보드와 터치, 소리 ON OFF, 호흡 창 복귀를 실제 브라우저에서도 확인해줘. 실패한 항목은 고친 뒤 다시 검사해줘.

완료 확인

자동 검사 결과가 모두 PASS입니다. 브라우저 오류 기록이 없습니다. 1단계와 10단계를 실제로 플레이할 수 있습니다. 창을 다른 곳으로 옮겼다가 돌아오면 일시 정지가 작동합니다.

프로젝트 폴더에서 실행하는 검사 명령

오류를 요청하는 문장 예시

5단계에서 플레이 시작을 누르고, 왼쪽 이동 2번 뒤 스페이스를 누르면 블록은 고정되지만 점수가 바뀌지 않아. 기대 결과는 즉시 낙하한 칸 수의 2배가 점수에 추가되는 것이야. 이 순서로 재현하고 관련 점수 계산만 수정해줘.

위 오류 문장은 보고 방법을 보여주는 예시입니다. 현재 게임에서 그 오류가 발생한다는 뜻은 아닙니다.

제작 10단계 독립 실행 파일과 공개 웹으로 배포하기

직접 여는 파일과 누구나 접속하는 웹 주소를 각각 준비합니다.

독립형은 HTML 안에 CSS와 JavaScript를 모두 넣은 단일 파일입니다. 파일을 두 번 눌러 브라우저에서 열 수 있고 게임 실행에 인터넷이 필요하지 않습니다. 공개 웹형은 같은 게임 파일을 호스팅에 올린 형태입니다. 로컬 미리보기 주소는 다른 사람이 접속하는 공개 주소가 아닙니다.

AI 요청 예시

최종 게임의 CSS와 JavaScript를 모두 포함한 단일 HTML 파일을 만들어줘. 외부 파일 없이 실행되게 해줘. 같은 버전을 공개 웹으로 배포하고 누구나 링크로 접속하도록 공개 범위를 설정해줘. 배포 성공과 실제 게임 시작을 확인한 뒤 링크를 알려줘.

완료 확인

독립형 HTML을 다른 폴더로 옮겨도 실행됩니다. 공개 주소에서 게임 제목과 최신 색상과 10단계 선택이 보입니다. 다른 사람에게 링크를 보내 접속을 확인합니다. 수정 후에는 독립형 파일도 다시 생성합니다.

게임과 설명서와 추가 카드의 변경 내역을 확인한 후 main에 커밋합니다. 저장소의 최신 상태가 작업 중 바뀌었다면 새 내용을 먼저 확인한 뒤 다시 반영합니다. 게임 제작용 호스팅 설정과 저장소 사이트의 배포 설정을 혼동하지 않습니다.
