지원 안내
✅ TXT·MD: 글자 읽기 → 문제 입력창
✅ HWPX(새 한글): 문서의 글자 추출 → 문제 입력창
📄 PDF: 파일 첨부 → AI 연결 시 문서 분석
⚠️ HWP(구형 한글): 현재 직접 해독하지 못해 HWPX·PDF·TXT로 변환해야 합니다.

HWPX 안에 그림으로 들어간 문제는 글자가 추출되지 않을 수 있습니다. 사진으로 별도 첨부하세요.

문제를 소리 내어 말하면 위 문제 입력란에 받아 적습니다. Chrome/Edge 등 음성 인식 지원 브라우저에서 사용할 수 있습니다.

음성 인식 대기 중

📡 Wi-Fi/IP 카메라 연결

같은 네트워크에 있는 카메라가 제공하는 HTTPS 스냅샷 JPG 주소를 입력하세요. 카메라의 CORS 허용이 필요합니다.

일반 Wi-Fi 카메라 영상, RTSP, HTTP 로컬 주소는 브라우저에서 직접 접속하지 못할 수 있습니다. 인증·CORS·HTTPS 설정이 필요하며 원격 페어링은 현재 지원하지 않습니다.
학습용 AI는 답을 잘못 읽거나 계산할 수 있습니다. 검산으로 확인하세요. 사진·파일은 AI 서버 연결 시 문제 분석용으로 전송됩니다.

간단한 수학 계산은 기본 풀이 기능으로 이용할 수 있습니다. 일반 교과·사진·PDF 분석은 서버 AI 연결이 필요합니다.
